# Production Inventory Optimization Dashboard

# Executive Summary

The Production Inventory Optimization Dashboard project was developed to analyze and optimize inventory operations using SQL Server, MySQL, Power BI, Power Query, and DAX. The project focuses on transforming raw inventory and operational data into interactive business intelligence dashboards that support data-driven decision-making and operational efficiency.

The workflow begins with importing and managing inventory data within a SQL Server test environment, where SQL joins and data transformation techniques are applied to prepare reporting-ready datasets. The project then transitions from a test environment to a production environment by integrating MySQL databases and establishing equivalent SQL workflows for scalable reporting and analytics.

Power BI dashboards were developed to visualize critical inventory and financial performance metrics, including average demand per day, average availability per day, total supply shortage, total profit, total loss, and average daily loss. DAX measures and KPI cards were implemented to provide clear business insights and improve visibility into operational performance.

The dashboard enables organizations to monitor inventory shortages, evaluate financial losses, identify demand trends, and optimize inventory planning processes. By combining SQL-based data engineering workflows with interactive business intelligence reporting, the project demonstrates how modern analytics tools can support production optimization and strategic business decision-making.

This project also highlights practical industry skills in SQL, MySQL, Power BI, Power Query, DAX, data cleaning, relational data modeling, and production-level reporting workflows. The overall solution reflects a real-world business intelligence pipeline designed to improve operational visibility and support inventory management strategies.

# Project Workflow

## 1. Test Environment Setup
- Installed SQL Server and MySQL Workbench
- Imported inventory dataset into SQL Server test environment
- Prepared reporting-ready tables using SQL joins

## 2. Data Preparation
- Applied LEFT JOIN operations in SQL Server
- Cleaned and transformed inventory data
- Validated data consistency before reporting

## 3. Power BI Dashboard Development
- Connected Power BI Desktop to SQL Server
- Built KPI cards and DAX measures
- Developed inventory optimization dashboards

## 4. Production Environment Migration
- Transitioned reporting workflow from test to production environment
- Imported data into MySQL database
- Created equivalent SQL logic in MySQL Workbench
- Connected Power BI to MySQL production database
- Published production-ready dashboards
